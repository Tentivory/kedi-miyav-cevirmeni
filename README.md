# Kedi Miyav Çevirmeni

## Resmi Tanım

Bu repository, insan dilini kedi miyavlarına çeviren dünyanın **en ciddi**, **en resmi** ve **en gereksiz** çeviri motorudur.

### Özellikler

- Gerçekten çalışır.
- Gerçekten miyavlar üretir.
- Her kelimenin uzunluğuna göre farklı yoğunlukta miyav üretir.
- Rastgele "mrrrow" ve "purr" ekleri ile doğallık katar.
- Kedilerin düşünme süresini simüle eder (0.05 saniye).
- Boş girişte otomatik "merhaba dünya" çevirisi yapar.

### Nasıl Kullanılır

```bash
python kedi_miyav_cevirmeni.py
```

Sonra metin girin. Çıktıyı bir kediye okuyun. Anlarlar.

### Bilimsel Dayanak

Bu program, 47 yıllık kedi davranış araştırmalarına, 3 tane hayali akademik makaleye ve bir kedi sahiplerinin oybirliğiyle alınan karara dayanmaktadır. 

Hiçbir bilimsel dayanağı yoktur. Ama varmış gibi davranır.

### Uyarı

Bu çevirmeni gerçek kedilere karşı kullanmayın. Onlar zaten sizi anlıyor. Siz onları anlamıyorsunuz.
